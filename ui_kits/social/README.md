# Social UI kit — Laive AI

On-brand, ready-to-post templates built from the design system.

- **`index.html`** — gallery of all templates (scaled previews).
- **`social.jsx`** — templates + `SocialApp`, exports to `window`.

## Templates (native size)
- **Statement** (1080×1080) — big urgency line ("AI adoption is no longer optional").
- **Product spotlight** (1080×1080) — a product with its capabilities + CTA.
- **Stat** (1080×1080) — a hero metric in 3D copper (e.g. 60% ROI).
- **Announcement** (1080×1080) — the 3D copper logo + tagline.
- **Story** (1080×1920) — vertical hero for IG/FB/WhatsApp stories.

Each renders at native resolution inside a scaled `Frame`. To export a post,
screenshot the individual canvas at full size (remove the scale, or capture the
inner 1080 element). Swap copy freely — keep the eyebrow/label + logo + laiveai.com
lockup consistent.
