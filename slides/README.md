# Sample slides — Laive AI

Standalone 1280×720 slides matching the company-profile deck style (dark, gold,
hex motif). Each is a directly-editable HTML file that links `styles.css` and
uses brand assets — no build step.

- `01-title.card.html` — cover with the 3D copper logo + tagline.
- `02-product.card.html` — product layout (capabilities + outcome + index numeral).
- `03-stat.card.html` — big 3D-copper proof-point metric.
- `04-contact.card.html` — closing CTA + contact details.

Reuse the shared patterns: Michroma uppercase eyebrow, gold halo background,
`.text-gradient-gold` accent words, `.text-3d-copper` numerals, hex icon badges,
and the `laiveai.com` footer lockup.
