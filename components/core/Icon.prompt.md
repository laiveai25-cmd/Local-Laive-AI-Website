**Icon** — monoline glyph from Lucide, colored by `currentColor` (inherits text color). Matches the monoline stroke of the logo's brain.

```jsx
<Icon name="arrow-right" size={18} />
<span style={{ color: 'var(--accent)' }}><Icon name="shield-check" size={24} /></span>
```

Any [Lucide](https://lucide.dev) icon `name` works. Common Laive picks: `brain`, `bot`, `sparkles`, `shield-check`, `zap`, `workflow`, `phone`, `message-circle`, `trending-up`, `arrow-right`, `check`.
